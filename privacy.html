隱私權政策

一、本站現況

「台灣優惠情報站」是一個純靜態的資訊展示頁面：沒有會員註冊、沒有登入功能、沒有留言或表單，不會向使用者索取任何個人資料。本站目前使用 Vercel Web Analytics 統計匿名的整體流量，詳見第五條說明。

二、瀏覽紀錄

本站託管於 Vercel（並同步備援於 GitHub Pages），你造訪本站時，這些服務商可能依其隱私權政策（Vercel、GitHub），基於維運與安全目的記錄基本的伺服器存取紀錄（如 IP 位址、瀏覽器資訊），此部分由服務商負責處理，非本站所能控制。

三、主題偏好設定

本站的深色 / 淺色模式切換按鈕，會使用瀏覽器的 localStorage 在你自己的裝置本機端記住你的顯示偏好，這筆資料只存在你的瀏覽器裡，不會傳送到任何伺服器，也不具備個人識別性。

四、外部連結

本站各優惠卡片附有前往商家官網或新聞報導的連結，點擊後即離開本站，適用該第三方網站自身的隱私權政策，與本站無關，請自行留意。

五、目前使用的流量分析工具

本站使用 Vercel Web Analytics 統計整體瀏覽量與熱門頁面，用於了解網站經營狀況。這項工具不使用 Cookie，蒐集的是匿名化、彙總後的流量數據（例如頁面瀏覽數、概略地區、裝置類型），不會識別個別使用者身分，也不會跨網站追蹤你。詳見 Vercel Web Analytics 隱私權說明。

若本站日後為了解搜尋成效導入 Google Search Console，該服務僅讀取 Google 搜尋端的曝光與點擊統計，不會在本站植入任何追蹤程式碼或 Cookie。若未來進一步導入 Google Analytics 或廣告服務（如 Google AdSense），該等服務可能會透過 Cookie 蒐集瀏覽資料並用於廣告個人化，屆時本站會於本頁更新揭露所使用之服務名稱與蒐集範圍。

本政策若有修訂，將直接更新於本頁並調整上方「最後更新」日期，請不定期回來查閱最新版本。
