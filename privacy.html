一、本站現況

「台灣優惠情報站」目前是一個純靜態的資訊展示頁面：沒有會員註冊、沒有登入功能、沒有留言或表單，伺服器端（GitHub Pages）也不會為本站另外收集、儲存或處理任何使用者的個人資料。本站不使用任何追蹤型 Cookie，也未串接任何流量分析或廣告服務。

二、瀏覽紀錄

本站託管於 GitHub Pages，你造訪本站時，GitHub 本身可能依其隱私權聲明，基於維運與安全目的記錄基本的伺服器存取紀錄（如 IP 位址、瀏覽器資訊），此部分由 GitHub 負責處理，非本站所能控制。

三、主題偏好設定

本站的深色 / 淺色模式切換按鈕，會使用瀏覽器的 localStorage 在你自己的裝置本機端記住你的顯示偏好，這筆資料只存在你的瀏覽器裡，不會傳送到任何伺服器，也不具備個人識別性。

四、外部連結

本站各優惠卡片附有前往商家官網或新聞報導的連結，點擊後即離開本站，適用該第三方網站自身的隱私權政策，與本站無關，請自行留意。

五、未來若新增分析或廣告服務

若本站日後為維運需要導入網站流量分析（如 Google Analytics）或廣告服務（如 Google AdSense），該等服務可能會透過 Cookie 或類似技術蒐集匿名瀏覽資料、用於流量統計或廣告個人化。屆時本站會於本頁更新揭露所使用之服務名稱與蒐集範圍，你也可透過瀏覽器設定管理或封鎖相關 Cookie。

六、政策異動

本政策若有修訂，將直接更新於本頁並調整上方「最後更新」日期，請不定期回來查閱最新版本。
